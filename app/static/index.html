Welcome to the pod

You have just joined an AI pod (a Lead AI Engineer and two AI Engineers) at Meridian Basin Energy Services, a fictional oilfield services company. The business wants agentic AI for Supply Chain, Finance and HR. Everything here is live: real LLM calls, a real LangGraph agent, real evals and real traces.

What each module practices

ModuleJob description requirement
RAG labBuild RAG: ingestion, retrieval, orchestration, response generation. Measure accuracy and hallucination rate.
Agent labAgents with tool calling, memory, multi-step reasoning and decision logic (LangGraph). Reliability and trust.
Coding labStrong Python fundamentals, with hidden tests run in an isolated sandbox.
Mock interviewExplain what you built, why, and how trust, accuracy and reliability were established.
Stakeholder role-playPartner with business stakeholders to find automation opportunities.
Code reviewProduction readiness, evaluation rigour and security judgement.
TracesMonitoring and observability for AI systems.

Suggested 90-minute loop

  1. Skim the company data and policies (5 min).
  2. RAG lab: run the baseline eval, find why it hallucinates, and fix it (20 min).
  3. Agent lab: the procurement agent breaks policy. Make all 6 scenarios pass (25 min).
  4. Coding lab: one exercise (15 min).
  5. Mock interview: explain what you just changed and why (15 min).
  6. Stakeholder role-play (10 min).
